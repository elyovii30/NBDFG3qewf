# MOSTAX Store

متجر إلكتروني عربي RTL بتصميم أسود وذهبي، مبني باستخدام React + Vite + Supabase.

## الموجود في المشروع
- واجهة متجر متجاوبة مع البحث والتصنيفات.
- سلة مشتريات ونموذج طلب باسم العميل ورقم الهاتف والعنوان.
- لوحة إدارة محمية بتسجيل دخول Supabase.
- إدارة المنتجات (إضافة/تعديل/إخفاء).
- مشاهدة الطلبات وأرقام العملاء والتواصل عبر WhatsApp.
- تغيير حالة الطلبات وتحديثات مباشرة للطلبات الجديدة.

## تشغيل محلياً
1. ثبّت Node.js (الإصدار 18 أو أحدث).
2. افتح مجلد المشروع في VS Code.
3. نفّذ:
   ```bash
   npm install
   ```
4. انسخ `.env.example` إلى ملف باسم `.env` وضع بيانات مشروع Supabase:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
   - `VITE_WHATSAPP_NUMBER` رقم واتساب بصيغة دولية بدون + أو مسافات، مثال مصر يبدأ بـ 20.
5. افتح Supabase > SQL Editor وشغّل محتوى `supabase/schema.sql`.
6. من Supabase > Authentication > Users أنشئ مستخدم المدير بنفسك. لا يوجد تسجيل مدير من واجهة المتجر.
7. شغّل:
   ```bash
   npm run dev
   ```
8. افتح الرابط الذي يظهر في الطرفية.

## النشر
ارفع المشروع إلى GitHub ثم اربطه بخدمة استضافة تدعم Vite مثل Vercel أو Netlify. أضف متغيرات البيئة الثلاثة نفسها في إعدادات الاستضافة ثم انشر.

## مهم قبل استقبال عملاء حقيقيين
- هذا مشروع تأسيسي قابل للتشغيل بعد إعداد Supabase، وليس متجراً منشوراً أو متصلاً بقاعدة بيانات حتى تضيف مفاتيح مشروعك.
- لا تضع `service_role` key في الواجهة مطلقاً؛ استخدم anon/publishable key فقط مع سياسات RLS.
- سياسات SQL الحالية تعطي دور `authenticated` صلاحيات الإدارة. في الاستخدام التجاري، اجعل حسابات الإدارة محكومة بدور admin مخصص (JWT claim / جدول صلاحيات) قبل إضافة أي حسابات مستخدمين عاديين.
- تحقق من إجمالي الطلب والمخزون على الخادم قبل الإنتاج، وأضف حماية من الطلبات الآلية/الإغراق، وسياسة خصوصية وشروط استبدال وشحن.
- بيانات المنتجات التجريبية تظهر فقط عندما لا يكون Supabase مضبوطاً؛ لن يتم حفظ الطلبات قبل ربط قاعدة البيانات.
